The **Code Review Agent** acts as an automated peer reviewer. While the [BA Agent](/docs/agents/ba-agent) focuses on *what* should be built, the Code Review Agent focuses on *how* it was built, checking whether the final code is clean, efficient, and consistent with the rest of your repository.

## Core Responsibilities

The Code Review Agent is responsible for the final polish and validation of a generated change:

<CardGroup cols={2}>
  <Card title="Semantic Analysis" icon="brain">
    Goes beyond basic linting to understand the logic and data flow, catching potential bugs or performance bottlenecks before they reach a human reviewer.
  </Card>
  <Card title="Style Guide Enforcement" icon="file-signature">
    Learns and applies your repository's specific coding patterns, naming conventions, and architectural preferences.
  </Card>
  <Card title="PR Summarization" icon="list">
    Generates the [Code Review and Summarization](/docs/build/pre-build-workflows#code-review-and-summarization) found in your pull requests, explaining the implementation details in plain language.
  </Card>
  <Card title="Fix Suggestions" icon="wrench">
    Identifies areas for improvement and leaves inline suggestions directly on the pull request for human reviewers to consider.
  </Card>
</CardGroup>

## Integration with Pre-Build Workflows

The Code Review Agent's behavior is directly controlled by your **[Pre-Build Workflows](/docs/build/pre-build-workflows)**. Through the YAML configuration, you can decide:

- **Comment Style**: Choose between balanced, concise, or verbose reviews.
- **File Exclusions**: Skip automated reviews for specific directories or file types.
- **Auto-Fixing**: Enable or disable automated suggestions for common issues.

## Why use the Code Review Agent?

- **Reduced Review Time**: Human reviewers can focus on high-level architecture rather than catching simple style or logic errors.
- **Consistency**: Helps generated code follow the patterns your team already uses.
- **Traceability**: Provides a clear explanation of *why* certain implementation choices were made.

<Note title="Collaborative Review">
  The Code Review Agent is designed to work *with* your team. It handles the "first pass" of the review process, allowing your engineers to spend their time on the most critical parts of the change.
</Note>
