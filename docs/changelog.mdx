## May 2026

- **Documentation refresh**: Reorganized the docs around the Build, Deploy, Observe, Control, Agents, Enterprise, and Guides areas.
- **Configuration guides**: Added service-preset walkthroughs for web apps, web services, cron services, databases, storage buckets, and cache resources.
- **Observability updates**: Expanded logs, metrics, activity timeline, and past deployment guidance for release verification and incident review.

## April 2026

- **Repository setup**: Improved guidance for connecting source control and configuring application delivery context.
- **Preview environments**: Added documentation for validating pull requests in isolated runtime environments.
- **Access control**: Expanded user, role, and service-management documentation.
