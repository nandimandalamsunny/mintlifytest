## New features

**AI Workflows are live.** Turn planning tickets into production-ready pull requests with full repository context. Delegate implementation, refactors, and boilerplate to parallel workflows while keeping humans in control of review and release. Learn more in [AI Workflows](/docs/ai-workflows/overview).

**Development Workflow.** Kick off scoped, executable tasks from a ticket and let Revolte handle context gathering, code generation, and validation end-to-end. See [Get started](/docs/ai-workflows/development-workflow/get-started).

**Quality Assurance and Product Strategy workflows.** Two new workflow types help you automate test planning and shape product decisions with context-aware AI. See [Quality Assurance](/docs/ai-workflows/quality-assurance) and [Product Strategy](/docs/ai-workflows/product-strategy).

**Deployments.** Ship and operate services from a single pipeline:
- [Web applications](/docs/deployments/services/web-applications) and [web services](/docs/deployments/services/web-services)
- [Cron jobs](/docs/deployments/services/cron-jobs)
- [Databases](/docs/deployments/services/databases/overview) with one-click [connection details](/docs/deployments/services/databases/connect)
- [Object storage](/docs/deployments/services/object-storage/overview) with a built-in [explorer](/docs/deployments/services/object-storage/explorer) and [local access](/docs/deployments/services/object-storage/local-access)
- [Cache](/docs/deployments/services/cache), [domains](/docs/deployments/services/domains), and [secrets](/docs/deployments/services/secrets)

**Observability.** Investigate every release with [deployment logs](/docs/deployments/observability/deployment-logs), [application logs](/docs/deployments/observability/application-logs), and [insights](/docs/deployments/observability/insights).

**Rollbacks.** Revert a bad release in a few clicks. See [Rollbacks](/docs/deployments/rollbacks).

**Deployment pipeline.** A unified view of build, validation, and release stages. See [Pipeline](/docs/deployments/pipeline).

**Dashboard with DORA metrics.** Track delivery health across teams with built-in [DORA metrics](/docs/dashboard/dora) and the [dashboard overview](/docs/dashboard/overview).

**`revolte.yaml` configuration.** Declare repo preferences, pipelines, environments, and resource specifications as code. Start with the [YAML overview](/docs/yaml/overview) and [syncing](/docs/yaml/syncing).

**Revolte CLI.** Manage workflows and deployments from your terminal. See the [CLI quick start](/docs/cli/quick-start) and [command reference](/docs/cli/reference).

**Integrations.** Connect your existing stack:
- Repository: [GitHub](/docs/integrations/repository/github) (GitLab and Bitbucket coming soon)
- Project management: [Jira](/docs/integrations/project-management/jira) (Linear and Azure DevOps coming soon)
- Cloud: [AWS](/docs/integrations/cloud/overview) (GCP and Azure coming soon)

## Updates

- Refreshed the [product overview](/docs/overview) with a clearer breakdown of the autonomous SDLC and a side-by-side platform comparison.
- Added a [Guides](/docs/guides/index) tab with end-to-end walkthroughs for [web apps](/docs/guides/deployments/web-apps), [web services](/docs/guides/deployments/web-services), [databases](/docs/guides/deployments/database), [storage](/docs/guides/deployments/storage), [cache](/docs/guides/deployments/cache), and [cron jobs](/docs/guides/deployments/cron).
