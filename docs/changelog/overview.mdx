## Revolte is here

The first release of Revolte brings autonomous AI software delivery into a single, governed workflow — from planning ticket to production rollout.

### New features

**AI Workflows.** Turn intent into production-ready pull requests. Delegate implementation, refactoring, and QA work to autonomous workflows that operate with full repository context. Learn more in [AI Workflows](/docs/ai-workflows/overview).

- [Development Workflow](/docs/ai-workflows/development-workflow/overview) — scope tickets into executable tasks and ship verified PRs.
- [Quality Assurance](/docs/ai-workflows/quality-assurance) — automated validation against your team's policies before review.
- [Product Strategy](/docs/ai-workflows/product-strategy) — high-level planning workflows that turn goals into scoped work.

**Deployments.** Run [web applications](/docs/deployments/services/web-applications), [web services](/docs/deployments/services/web-services), and [cron jobs](/docs/deployments/services/cron-jobs) on Revolte with environment-aware rollouts and automated health checks. See the [Deployments overview](/docs/deployments/overview).

**Managed services.** Provision the data layer alongside your app:

- [Databases](/docs/deployments/services/databases/overview) with a built-in [connection workflow](/docs/deployments/services/databases/connect).
- [Object Storage](/docs/deployments/services/object-storage/overview) with an [Explorer](/docs/deployments/services/object-storage/explorer) and [local access](/docs/deployments/services/object-storage/local-access).
- [Cache](/docs/deployments/services/cache), [Domains](/docs/deployments/services/domains), and [Secrets](/docs/deployments/services/secrets).

**Observability.** Real-time visibility into every rollout with [deployment logs](/docs/deployments/observability/deployment-logs), [application logs](/docs/deployments/observability/application-logs), and [insights](/docs/deployments/observability/insights).

**Rollbacks.** Revert any deployment in a single step from the past deployments view. See [Rollbacks](/docs/deployments/rollbacks).

**DORA dashboard.** Track delivery performance — deployment frequency, lead time, change failure rate, and recovery time — from the [Dashboard](/docs/dashboard/dora).

**`revolte.yaml` configuration.** Define services, environments, pipelines, and policies as code. Start with the [YAML overview](/docs/yaml/overview), configure [repo preferences](/docs/yaml/repo-preferences/app-branch-settings), and tune [environment settings](/docs/yaml/environment-settings/overview) per service.

**Pipelines.** Built-in [code quality](/docs/yaml/repo-preferences/pipelines/code-quality) and [test suite](/docs/yaml/repo-preferences/pipelines/test-suite) checks run automatically on every PR. See the [Pipelines overview](/docs/yaml/repo-preferences/pipelines/overview).

**CLI.** Drive Revolte from your terminal. Get going with the [CLI quick start](/docs/cli/quick-start) or browse the [command reference](/docs/cli/reference).

**Integrations.** Connect your existing stack on day one:

- **Cloud** — [AWS](/docs/integrations/cloud/overview) is live. GCP and Azure are coming soon.
- **Repository** — [GitHub](/docs/integrations/repository/github) is live. GitLab and Bitbucket are coming soon.
- **Project Management** — [Jira](/docs/integrations/project-management/jira) is live. Linear and Azure DevOps are coming soon.

### What's next

Browse the [Quick Start](/docs/quick-start) to ship your first autonomous workflow, or explore the [guides](/docs/guides/index) for end-to-end examples.
