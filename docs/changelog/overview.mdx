<Update label="May 15, 2026" tags={["launch"]}>
  ## Revolte is live

  Revolte launches as an AI-native software delivery platform. It connects planning, code generation, validation, pull request review, deployment, and observability into a single governed workflow. Take an idea from ticket to production while AI executes the work and you stay in control.

  ### New features

  **AI Workflows.** Turn planning tickets into reviewable pull requests with full repository context. The Development Workflow is available now, with Quality Assurance and Product Strategy coming soon. See [AI Workflows](/docs/ai-workflows/overview) and the [Development Workflow guide](/docs/ai-workflows/development-workflow/get-started).

  **Deployments and pipelines.** Orchestrate environments, monitor pipeline execution with manual gates, and recover quickly using one-click [rollbacks](/docs/deployments/rollbacks) to a known good version. Start with the [deployments overview](/docs/deployments/overview) and [pipeline guide](/docs/deployments/pipeline).

  **Managed services.** Provision and manage [web services](/docs/deployments/services/web-services), [web applications](/docs/deployments/services/web-applications), [databases](/docs/deployments/services/databases/overview), [cache](/docs/deployments/services/cache), [object storage](/docs/deployments/services/object-storage/overview), [cron jobs](/docs/deployments/services/cron-jobs), [secrets](/docs/deployments/services/secrets), and [custom domains](/docs/deployments/services/domains) directly from Revolte.

  **Observability.** Inspect [application logs](/docs/deployments/observability/application-logs), [deployment logs](/docs/deployments/observability/deployment-logs), and runtime [insights](/docs/deployments/observability/insights) without leaving the platform.

  **DORA dashboard.** Track delivery performance with industry-standard DORA metrics. See the [DORA dashboard](/docs/dashboard/dora).

  **YAML configuration.** Define your entire application lifecycle—services, environments, pipelines, pre-build steps, and agent workflows—in a single version-controlled file. See [YAML overview](/docs/yaml/overview).

  **CLI.** Bootstrap projects and run workflows from your terminal. See the [CLI quick start](/docs/cli/quick-start) and [reference](/docs/cli/reference).

  **Integrations.** Connect [GitHub](/docs/integrations/repository/github) for source control and [Jira](/docs/integrations/project-management/jira) for project management. Support for GitLab, Bitbucket, Linear, Azure DevOps, GCP, and Azure is on the way.

  **Team management.** Invite teammates and assign roles and permissions from [Users](/docs/users).

  **Guides library.** Step-by-step recipes for [deploying web apps](/docs/guides/deployments/web-apps), [web services](/docs/guides/deployments/web-services), [databases](/docs/guides/deployments/database), [storage](/docs/guides/deployments/storage), [cache](/docs/guides/deployments/cache), and [cron jobs](/docs/guides/deployments/cron-jobs/index).
</Update>
