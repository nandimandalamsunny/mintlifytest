---
title: "Web App Service"
description: "Configure repository preferences and environment settings for a web app service."
---

This guide walks through configuring a **Web App** service in Revolte. This preset is framework-agnostic and can be used to deploy any **Frontend Application**—including React, Next.js, Vue, Angular, Svelte, or simple static HTML sites—with automated edge delivery.

The configuration focuses on the Repo Preference and Environment Settings steps to help you set up your application confidently.


<Steps>
  <Step title="Choose a Preset">
    ![Choose Webapp Preset](/docs/image-v2/guides/web-app/web-app-1.png)

     Click **Webapp** to continue.
  </Step>

  <Step title="Repo Preference">
    The Repo Preference tab is identical across all service presets. See [Repository Preference](/docs/yaml/repo-preferences/overview) for a full walkthrough of each setting.
  </Step>

  <Step title="Web App — Environment Settings">
    ![Web App tab — QA environment](/docs/image-v2/guides/web-app/web-app-2.png)
    

    The **QA** environment tab is selected. You can switch between **Preview**, **QA**, **Staging**, and **Production** tabs to define environment-specific configurations. Changes made in one environment do not affect the others, allowing you to tailor scaling and variables for each stage of your pipeline.

    The center panel shows the Web App form for the active environment:

    - **Service Name** — Enter a unique identifier for this service (e.g., `web-app_service`).
    - **Entry Point** — The main file that starts the app (e.g., `index.js`).
    - **Properties**
      - **Index Page** — The default HTML page served to users (e.g., `index.html`).
      - **Error Page** — The fallback page shown when an error occurs (e.g., `error.html`).
      - **Enable CDN** — Toggle on to serve assets through a content delivery network for faster load times.
  </Step>

  <Step title="Variables & Secrets">
    Configure environment variables and encrypted secrets for your service. See [Variables & Secrets](/docs/yaml/environment-settings/resource-specifications/variables) for a detailed guide on managing environment-specific configurations.
  </Step>

  <Step title="Commit">
    At the bottom of the panel, fill in the **Commit Details**:

    - **File Name** — The configuration file to create or update in your repository (e.g., `revolte.yml`).
    - **Commit Message** — A short description of what you configured (e.g., `Add web app service`).
    - **Choose Branch** — The branch where the configuration file will be committed.

    Click **Commit** to save the configuration to your repository, or **Skip & deploy** to deploy immediately without committing.
  </Step>
</Steps>

> **Tip:** Always commit with a clear message before deploying to keep a traceable configuration history.
