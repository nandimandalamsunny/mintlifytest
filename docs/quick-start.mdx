Use this page when you are new to Revolte and want the shortest path through the product. It gives you a guided route from product understanding to your first generated feature, deployment, and release verification.

Revolte works best when you follow the lifecycle:

```txt
Requirement -> Build -> Validate -> Deploy -> Observe
```

## Before you start

You do not need a connected repository to read the overview. To complete the first build and deployment path, prepare:

- A Revolte account
- Access to the Git repository you want Revolte to work with
- Permission to create branches and pull requests
- Basic application details such as framework, build command, start command, and target branch

## Recommended path

<Steps>
  <Step title="Understand the product">
    Start with [Introduction to Revolte](/docs) to learn the platform model, core modules, and key terms.
  </Step>

  <Step title="Create your first feature">
    Use [Create Your First Feature](/docs/build/quick-start) to connect an application and submit a focused build request.
  </Step>

  <Step title="Validate the output">
    Review the pull request with [Validate Output](/docs/build/review-output) before merging generated code.
  </Step>

  <Step title="Deploy your application">
    Release approved code with [Deploy Your Application](/docs/deploy/quick-start), then confirm the target environment is healthy.
  </Step>

  <Step title="Monitor the release">
    Use [Monitor Your System](/docs/observe/quick-start) and [Logs](/docs/observe/logs) to verify behavior after deployment.
  </Step>
</Steps>
