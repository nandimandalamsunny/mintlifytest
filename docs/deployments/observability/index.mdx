Observability helps monitor deployments, runtime behavior, and application health across Revolte services.

## Signals

- [Deployment Logs](/docs/deployments/observability/deployment-logs) — Build, deployment, and health check logs.
- [Application Logs](/docs/deployments/observability/application-logs) — Runtime logs emitted by applications and services.
- [Insights](/docs/deployments/observability/insights) — AI-generated anomalies and deployment recommendations.
