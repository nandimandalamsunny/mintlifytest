The Revolte CLI enables developers to authenticate, initialize workflows, and execute development tasks seamlessly from their local environment.

## Requirements

| Requirement | Minimum | Notes |
| --- | --- | --- |
| Node.js | 20 | Required for npm installation and many JavaScript builds. |
| Git | 2.40 | Required for repository-aware workflows. |
| Shell | bash, zsh, or fish | Used by install scripts and command examples. |
| Network | HTTPS access | Required for Revolte API and provider integrations. |

## Install

<CodeBlock language="bash" filename="Terminal">
{`npm install -g @revolte.ai/cli`}
</CodeBlock>

---

## Verify Installation

<CodeBlock language="bash" filename="Terminal">
{`revolte --help`}
</CodeBlock>

---

## Authenticate

<CodeBlock language="bash" filename="Terminal">
{`revolte login`}
</CodeBlock>

<Tip>
  Run `revolte login` to authenticate your CLI session. This will open a browser window to complete the login process.
</Tip>
