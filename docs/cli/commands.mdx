Use the Revolte CLI to manage your development lifecycle directly from the terminal. The CLI provides a streamlined set of commands to authenticate, start workflows, and execute development tasks.

## Available Commands

| Command | Purpose |
| --- | --- |
| `revolte start` | Start the Revolte workflow. |
| `revolte develop` | Execute development tasks. |
| `revolte login` | Authenticate the CLI with your Revolte account. |
| `revolte help` | Show help for all commands. |

## Global Options

| Option | Description |
| --- | --- |
| `--version` | Show the current version of the CLI. |
| `--help` | Show help information. |

## Examples

<CodeBlock language="bash" filename="Terminal">
{`revolte start
revolte develop
revolte login
revolte --version`}
</CodeBlock>

<Info>
  Use `revolte <command> --help` to get more details about a specific command.
</Info>
