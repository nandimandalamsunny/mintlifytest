The **Prebuild Pipeline** ensures that every Pull Request is analyzed for quality, risk, and compliance before it reaches the build stage.

## Code Review & Summarization

Revolte automatically analyzes changes to provide:

- **Summaries**: High-level explanations of what the PR changes for reviewers.
- **Fix Suggestions**: AI-generated improvements for potential bugs or style issues.
- **Risk Assessment**: Highlighting changes to sensitive areas like database migrations or security configs.

## Pipeline Controls

You can toggle specific checks within your `revolte.yaml`:

```yaml revolte.yaml
config:
  codeReview:
    summarize: true
    suggestFixes: true
    commentStyle: Balanced
```
