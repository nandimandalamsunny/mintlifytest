The **Agent Workflow** enables Revolte's AI agent to assist you directly within your repository context.

## Capabilities

Once enabled, the Revolte agent can:

- **Generate Code**: Create new features or components based on your existing codebase patterns.
- **Debug Errors**: Analyze runtime logs or build failures to suggest and apply fixes.
- **Execute Tasks**: Automate repetitive tasks like dependency updates or boilerplate generation.

## Configuration

In your `revolte.yaml`, you can toggle this workflow globally:

```yaml revolte.yaml
workflow:
  developerWorkflow:
    enabled: true
```
