---
title: "Preset & Service"
description: "Configure automated build and deployment workflows."
---

The **Preset & Service** settings define the automated path from a merged Pull Request to a running service in your targeted environment.

## Deployment Workflows

This configuration defines:

- **Build Presets**: Pre-configured build steps for your chosen framework.
- **Rollout Strategy**: How new versions are deployed (e.g., Rolling updates, Canary).
- **Health Verification**: Defining the criteria for a successful deployment.

## Configuration Example

```yaml revolte.yaml
revolte:
  env:
    production:
      branch: main
      services:
        rid_1:
          type: WEB_SERVICE
          name: api-service
```
