Revolte uses a powerful variable system that allows you to reference other services and manage sensitive secrets across environments.

## Environment Variables

Define flat key-value pairs that your application can access at runtime.

```yaml revolte.yaml
revolte:
  version: "1.0"
  project: Demo-Project
  appName: "demo-app"
  env:
    production:
      branch: main
      services:
        rid_1:
          type: WEB_SERVICE
          properties:
            variables:
              # Static Variables
              NODE_ENV: production
              LOG_LEVEL: info
              # Dynamic Reference
              DATABASE_HOST: "#{db.dbUrl}"
              # Secret Injection
              STRIPE_SECRET_KEY: "#{STRIPE_SECRET_KEY}"
```
