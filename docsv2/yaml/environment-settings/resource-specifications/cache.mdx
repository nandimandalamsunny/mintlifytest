---
title: "Cache"
description: "Cache services (like Redis) require prioritized memory to ensure low-latency data retrieval."
---

## Memory Allocation

| Parameter           | Recommended   | Description                            |
| ------------------- | ------------- | -------------------------------------- |
| **Memory**          | `1 GB`        | Dedicated RAM for the caching layer.   |
| **Eviction Policy** | `allkeys-lru` | How the cache handles memory pressure. |

## Configuration

```yaml revolte.yaml
revolte:
  version: "1.0"
  project: Demo-Project
  appName: "demo-app"
  env:
    production:
      branch: main
      services:
        rid_1:
          type: DATABASE
          name: redis-cache
          specifications:
            memory: 2
```
