Use the CLI for repository-aware workflows and repeatable operations. Commands follow the shape revolte resource action with flags for project, service, and environment scope.

## Core commands

| Command | Purpose |
| --- | --- |
| revolte auth login | Start a browser-based login flow. |
| revolte workspace use | Select the active workspace. |
| revolte project create | Create a project. |
| revolte repo connect | Connect a Git repository. |
| revolte init | Generate revolte.yaml for a repository. |
| revolte config validate | Validate YAML configuration. |

## Deployment commands

| Command | Purpose |
| --- | --- |
| revolte deploy SERVICE | Deploy a service to an environment. |
| revolte deploy list | List recent deployments. |
| revolte deploy compare | Compare two deployments. |
| revolte rollback SERVICE | Roll back a service to a past deployment. |
| revolte cron run JOB | Run a cron job manually. |

## Observability commands

| Command | Purpose |
| --- | --- |
| revolte logs deployment | Stream deployment pipeline logs. |
| revolte logs app | Stream application logs. |
| revolte metrics | Query runtime metrics. |
| revolte insights list | List active AI insights. |

## Examples

<CodeBlock language="bash" filename="Terminal">
{`revolte deploy checkout-api --env staging --follow
revolte logs app checkout-api --env production --level error --since 2h
revolte metrics checkout-api --deployment dep_7f42c9 --compare previous
revolte rollback checkout-api --env production --to dep_1a8e2b`}
</CodeBlock>

## Global flags

| Flag | Description |
| --- | --- |
| --project | Project slug. |
| --env | Target environment. |
| --service | Service name when not part of the positional command. |
| --file | Configuration file path. |
| --output | Output format, such as table or json. |
| --follow | Stream updates until the operation completes. |

<Info>
  Commands that change production state require the same permissions and approval policy as dashboard actions.
</Info>
