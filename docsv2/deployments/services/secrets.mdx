---
title: "Secrets"
description: "Manage encrypted environment variables, scoping, injection, and rotation."
---

Secrets store sensitive values such as database credentials, API keys, and signing keys. Revolte encrypts secrets and injects them only into the environments and services that need them.

## Secret scopes

| Scope | Use for |
| :--- | :--- |
| **Workspace** | Shared credentials managed by platform administrators. |
| **Project** | Values used by multiple services in one project. |
| **Environment** | Values that differ between staging and production. |

## Add a secret

<Tabs>
  <Tab title="CLI">
    <CodeBlock language="bash" filename="Terminal">
{`revolte secret set STRIPE_SECRET_KEY \\
  --project demo-project \\
  --env production`}
    </CodeBlock>
  </Tab>
  <Tab title="YAML binding">
    <CodeBlock language="yaml" filename="revolte.yaml">
  {`revolte:
  env:
    production:
      services:
        rid_api_1:
          type: WEB_SERVICE
          properties:
            variables:
              STRIPE_SECRET_KEY: '#{secrets.STRIPE_SECRET_KEY}'`}
</CodeBlock>
  </Tab>
</Tabs>

<Warning>
  Never put secret values directly in `revolte.yaml`. Store only references and bindings in configuration.
</Warning>
