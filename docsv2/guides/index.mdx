Environment settings change how the same services behave across preview, staging, and production. Use these to manage specific branches, variable overrides, and scaling rules for each stage of your project.

## Configuration Precedence

Revolte applies configuration using a hierarchical priority system.

| Priority | Source               | Description                                      |
| -------- | -------------------- | ------------------------------------------------ |
| **1**    | Environment Override | Settings defined within a specific `env` block.  |
| **2**    | Service Default      | Settings defined in the global `services` block. |
| **3**    | Project Default      | Top-level project defaults in `revolte.yaml`.    |
| **4**    | Platform Default     | Revolte's internal system defaults.              |
