## New features

**AI Workflows are live.** Turn planning tickets into production-ready pull requests with full repository context. Delegate implementation, refactors, and boilerplate to parallel workflows while keeping humans in control of review and release. Learn more in [AI Workflows](/ai-workflows/overview).

**Development Workflow.** Kick off scoped, executable tasks from a ticket and let Revolte handle context gathering, code generation, and validation end-to-end. See [Get started](/ai-workflows/development-workflow/get-started).

**Quality Assurance and Product Strategy workflows.** Two new workflow types help you automate test planning and shape product decisions with context-aware AI. See [Quality Assurance](/ai-workflows/quality-assurance) and [Product Strategy](/ai-workflows/product-strategy).

**Deployments.** Ship and operate services from a single pipeline:
- [Web applications](/deployments/services/web-applications) and [web services](/deployments/services/web-services)
- [Cron jobs](/deployments/services/cron-jobs)
- [Databases](/deployments/services/databases/overview) with one-click [connection details](/deployments/services/databases/connect)
- [Object storage](/deployments/services/object-storage/overview) with a built-in [explorer](/deployments/services/object-storage/explorer) and [local access](/deployments/services/object-storage/local-access)
- [Cache](/deployments/services/cache), [domains](/deployments/services/domains), and [secrets](/deployments/services/secrets)

**Observability.** Investigate every release with [deployment logs](/deployments/observability/deployment-logs), [application logs](/deployments/observability/application-logs), and [insights](/deployments/observability/insights).

**Rollbacks.** Revert a bad release in a few clicks. See [Rollbacks](/deployments/rollbacks).

**Deployment pipeline.** A unified view of build, validation, and release stages. See [Pipeline](/deployments/pipeline).

**Dashboard with DORA metrics.** Track delivery health across teams with built-in [DORA metrics](/dashboard/dora) and the [dashboard overview](/dashboard/overview).

**`revolte.yaml` configuration.** Declare repo preferences, pipelines, environments, and resource specifications as code. Start with the [YAML overview](/yaml/overview) and [syncing](/yaml/syncing).

**Revolte CLI.** Manage workflows and deployments from your terminal. See the [CLI quick start](/cli/quick-start) and [command reference](/cli/reference).

**Integrations.** Connect your existing stack:
- Repository: [GitHub](/integrations/repository/github) (GitLab and Bitbucket coming soon)
- Project management: [Jira](/integrations/project-management/jira) (Linear and Azure DevOps coming soon)
- Cloud: [AWS](/integrations/cloud/overview) (GCP and Azure coming soon)
